NUFTEXT

Generative Type Tools · WebGL & SVG · Zero dependencies

Three single-file browser tools for building poster typography out of noise fields, fluid simulation and colour ramps. Nothing to install and no build step — every tool is one HTML file that runs offline once loaded.

Tools

Flagship

Nuftext Studio

Layered poster generator built on a thermal halo pipeline. Text and pattern layers become silhouettes, blur into blobs and halos, then get looked up through an editable RGBA palette. Includes a melt simulation, twelve pattern modes, blend modes, font upload and PNG/WebM export.

WebGL

Scorch / Noise

Burnt text generator. A noise field warps the letterform edges while a second field carves holes through it, then a multi-scale glow pyramid and thermal ramp light the result. Four palettes, live smoulder, high-resolution PNG export.

Open tool →
SVG filters

Liquid / Glow

Vector-native melt typography. A modular <filter> chain fuses letters with a gooey alpha-contrast pass, warps them through animated turbulence, and blooms a mottled glow behind the sharp text. Exports SVG, PNG and WebM.

How the studio pipeline works

  1. Source — text is typeset to a mask (optionally run through a melt simulation and burnt-edge noise); the background pattern is evaluated as a scalar density field.
  2. Silhouette — each source is thresholded to a hard shape, with adjustable sensitivity and an invert switch.
  3. Blob — the silhouette is blurred and contrast-boosted, turning jagged edges into a soft, defined shape.
  4. Halo — the blob is blurred again, much wider. This falloff is what becomes the glow.
  5. Palette lookup — halo brightness indexes an RGBA gradient. Stop opacity is the alpha cutout, so the background shows through wherever the field runs cold.
  6. Composite — layers land on the background fill through independent blend modes.
  7. Grain — a per-frame noise texture composites in overlay mode, darkening shadows and lifting highlights rather than flatly adding to both.

Notes

  1. Requires WebGL for the studio and Scorch; Liquid/Glow needs only SVG filter support.
  2. Fonts — four display faces load from Google Fonts, and any local .ttf/.otf/.woff can be uploaded into the studio at runtime.
  3. Everything is client-side. No uploads leave the browser and there is no backend.
